# 🌦️ WeatherGPT

## AI-Powered Hyperlocal Weather Risk & Decision Intelligence Platform

WeatherGPT transforms complex weather information into personalized,
actionable decisions.

### Core Pipeline

Weather Data
→ Hazard
→ Impact
→ Risk
→ Decision
→ Action

### Project Structure

- `backend/` — FastAPI backend
- `frontend/` — React frontend
- `data/` — Weather and historical data
- `ml/` — Machine learning experiments
- `docs/` — Documentation
- `tests/` — Testing
- `scripts/` — Utility scripts

### Backend

The backend is built using FastAPI.

### Core Principle

WeatherGPT does not replace authoritative weather forecasting.
It acts as an intelligence and decision-support layer between
weather information and human action.
